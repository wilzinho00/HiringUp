Termos de Uso e Política de Privacidade

Transparência, segurança e responsabilidade no uso da plataforma Hiring UP.

1. Sobre a Plataforma

A Hiring UP é um projeto acadêmico desenvolvido com fins educacionais, com o objetivo de simular um ambiente profissional de recrutamento e seleção.

Este sistema foi desenvolvido por Wilciano Nascimento, Pedro Rogério, Bruno Momesso e Kainã Alves como parte de atividades acadêmicas relacionadas ao desenvolvimento web.

2. Cadastro de Usuários

Os usuários podem realizar cadastro fornecendo informações básicas, como nome, e-mail e senha.

As informações cadastradas são utilizadas exclusivamente para fins de demonstração e funcionamento do projeto acadêmico.

3. Privacidade dos Dados

A Hiring UP respeita a privacidade dos usuários e busca seguir boas práticas inspiradas na Lei Geral de Proteção de Dados (LGPD).

  • Os dados não são comercializados.
  • Os dados não são compartilhados com terceiros.
  • As informações são utilizadas apenas dentro do ambiente do projeto.
  • O usuário pode solicitar a exclusão dos dados cadastrados.

4. Responsabilidades do Usuário

Ao utilizar a plataforma, o usuário concorda em:

  • Fornecer informações verdadeiras.
  • Não utilizar dados falsos ou de terceiros.
  • Não tentar comprometer a segurança do sistema.
  • Utilizar a plataforma de forma ética e responsável.

5. Limitações do Projeto

Este sistema possui caráter acadêmico e demonstrativo.

As vagas, empresas e funcionalidades apresentadas podem ser fictícias e utilizadas apenas para fins educacionais.

6. Alterações dos Termos

Estes termos poderão ser atualizados a qualquer momento para melhorias da plataforma e adequação às necessidades do projeto.

7. Contato

Para dúvidas relacionadas ao projeto Hiring UP, entre em contato com o desenvolvedor responsável.
