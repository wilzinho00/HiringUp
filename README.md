## 📌 Sobre o Projeto

O **Hiring Up** é um sistema web de vagas e empregos desenvolvido como Projeto Integrador (PI) da Fatec Itapira.

O objetivo do sistema é conectar estudantes e empresas através de uma plataforma moderna, responsiva e intuitiva para divulgação de vagas de estágio e emprego.

O projeto atualmente está focado no desenvolvimento **Front-End**, simulando funcionalidades reais de autenticação e navegação de usuários.

---

# 🎯 Objetivos do Sistema

- Facilitar divulgação de vagas
- Melhorar conexão entre alunos e empresas
- Simular fluxo real de autenticação
- Criar experiência moderna e responsiva
- Desenvolver interface profissional inspirada em plataformas reais
